## Decisions the plan left open, each the coordinator's to rule

1. **Two notes, not one.** The plan names `F1-INTERFACES.md`; the task asked for `F1-0.md`. Both are written: the
   first is the interface, this one the hand-over.
2. **A printed pair's assembly is not marked `_P`.** D10 is about parts, so `pair_stems`' assembly stem is
   unchanged. A printed and a machined pair of the same sizes then share `Pair_m…`, and the second is refused
   as existing. `spec.py` has no owner after F1-0, so whoever adds `_P` there needs the coordinator's word.
3. **A bad Process word or a printed spec's bad Nozzle is an error at its field.** `spur.field_errors` reads
   both, every kind going through it, so derive never meets them. The words are `process_value`'s and
   `nozzle_mm`'s. A machined spec's Nozzle is not read.
4. **Helpers beyond the plan's names**: `spur.printed_backlash`, `blank_backlash`, `backlash_expression`,
   `spec_nozzle` and `derived_dict`; `spec.PROCESSES`, `PROCESS_FIELDS` and `PRINTED_STEM_MARK`;
   `schema.PROCESS_WORDS`; `workbook_fixtures.machined_reads`.

   `nozzle=0.4`. `printed_backlash_expression(module_name="Module")` takes the global's name unquoted.
