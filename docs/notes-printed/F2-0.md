## Decisions the plan left open, each the coordinator's to rule

1. **Three notes.** `F2-INTERFACES.md` (the interface), `F2-PROBES.md` (the probe), this one (the hand-over), as F1-0.
2. **`PrintResult` is defined in `printout`**, not `swbuild` as the plan's list places it: `write_list` and `ui_text` take
   it, and `printout` must not import `swbuild` (`swbuild` imports `printout`; `workbook.update` imports `swbuild`, so
   `printout` takes the workbook's types as annotations only). `ui_text` imports `printout` and `gears.span` at run time.
3. **`SolidWorksVersion`**, which the plan names and the repo did not have, is `Tuple[int, ...]`, the revision, `()` for none.
4. **Names beyond the plan's**: `PrintPlan.revision`, `.name`, `.pressed` (the job's gate and the list's head);
   `PrintResult.warnings` (decision 9); keyword-only `now` and `exists` on both planners (tests); the module constants
   above; `span.NONE`; five `SolidWorks` Protocol lines in `swbuild` (`save_flags`, `activate`, `close_document`,
   `export_step`, `document_by_path`).
5. **`print_bar_line(plan: Optional[PrintPlan])`**: the plan left its arguments as "…"; it words the form's own plan.
6. **No new refusal code** for "no SolidWorks connected" or "SolidWorks changed since the plan": both are `GATE`, the
   detail telling them apart (`{}`; `planned_year`, `planned_revision`). `NO_PART` also covers a part on record that is not
   on disk (detail "not on disk").
7. **The order of the refusals** (`F2-INTERFACES.md` §2.2): the gate first, then the form's or the window's own; in the
   job `COMPONENT_ONLY`, `MODIFIED`, `GLOBALS_DIFFER`, `FEATURE_IN_ERROR`. Each code's `detail` keys are fixed there.
8. **The sentences** of §2.3 are drafts where the plan gives none (it gives the gate's and `COMPONENT_ONLY`'s); C owns
   them.
9. **A feature warning does not refuse** (the re-check's should-fix): an error refuses, a warning is named in the result
   and the list.
10. **The extent check never refuses a part with the user's features** (re-check), and is skipped as a fact for bevel
    gears, rings, sleeves, dogs and hubs, whose outer radius or length is not d_a / 2 and the face width; it is built
    only if probe step 3 bears it out.
11. **`SAVE_AS_COPY` stays one name**, as `SAVE_AS_SILENT`, set when both versions' runs propose the same value.
12. **`PART_WINDOW_READ_ON_<year>` is a sixth finding** the plan does not list. The job's way for a part depends on
    whether it is open in its own window or only as a component (§3.1.3), and nothing in the app tells them apart; without
    it the fallback could close a window the user had. The probe proposes it from `Visible` or `ActiveView`. While it is
    None only the active document counts as in its own window, and an inactive open part is exported by its object only
    when both `FROM_COMPONENT` is True and `NEEDS_ACTIVE` is False, else refused (`F2-INTERFACES.md` §5.2). Dropping it
    would leave those parts always refused.
13. **Lightweight** (re-check): a part not found while any assembly is open is opened beside only when
    `OPEN_BESIDE_ASSEMBLY_CLOSES_CLEAN` is True (it may be a lightweight component); both component findings are proposed
    True only if probe step 7c covers the lightweight case. The job never changes a component's state.
14. **`document_by_path`'s route** is left to the probe's review: `GetOpenDocumentByName` is measured (first use) beside the
    verified document walk, which the probe also asks whether it reaches a component-only document.
15. **The probe's judgements are stricter than the plan's wording in three places**: `STEP_EXPORT` also needs both files
    to pass §3.1.4's frame check; "the file is right" (step 6, 7) is judged only when two exports of one document repeat
    but for `FILE_NAME` (step 5 and 7d are those controls), and a file whose text differs with the same geometry is
    "cannot tell" (None), not wrong; a step whose start was already marked proposes None. Booleans are proposed True,
    False or None (cannot tell).
16. **The probe's shapes**: the helical part's face is 10 mm (the plan gives none); the spur is activated before step 8,
    so that step does not rest on step 6's answer; step 7 is split (a) to (d), (d) making the reference files; the
    component section reads `swconst.tlb` itself when run alone. Step 8 of the first revision is not run, as the plan
    proposes; this confirms that proposal for the probe.
17. **Nothing personal in a log**: no path but relative to the run's output folder, no STEP header (its `FILE_NAME` holds an
    author and an organisation); the STEP files stay in the run folder and are not to be committed.
18. **The β 30° test row** is built at face 14 mm (re-check); **Coupon_E for a shaft over 18 mm** is module 1.5, 20 teeth
    (re-check), put in C's instructions (`README.md`). PLAN-PRINTED §3.2 itself is not edited by F2-0: the coordinator may
    want the same sentence there.
19. **A citation**: the plan's `HelicalDerived.half_width` is `toothed_width` (`helical.py:180-183`).
20. **W9a's `main` starts its own Excel** for every run of the harness, the probe's included; the probe asks nothing of it.
    Changing that would change W9a's script, which F2-0 does not own.
